# Plugin Bricks (MCP Marketplace)

This directory serves as the dynamic capability marketplace for Crimson OS. It operates as a decentralized **"App Store for Intelligence."**

## The "Brick" Concept
A "Brick" is a modular, pre-formatted Model Context Protocol (MCP) server, toolset, or script. Instead of hardcoding API integrations or locking capabilities behind centralized SaaS subscriptions, capabilities are packaged as Sovereign Bricks created by domain experts.

## Drop-In Capability
To give an agent a new capability, the user simply drops a Brick into the folder structure. The system automatically detects the Brick via its `.json` manifest and immediately grants the targeted agent (or the entire Agent Stack) access to those specific tools.

*   **The Scenario:** When a user logs into Stripe on their browser, the OS recognizes the workflow and suggests the user acquire a "Stripe Finance Brick" (or a "CPA Auditor Brick") built by a verified domain expert. 
*   **The Execution:** The user buys the Brick, drops it into the system, and suddenly Q and N.E.O. have the ability to run full-scale financial audits locally.

## Two-Tier System
*   **User Level:** Drag-and-drop pre-compiled blocks to instantly gain new capabilities via the UI.
*   **Developer Level (Micro-Legos):** Direct access to modify the granular logic trees, sequence gates, and context parsing variables inside the Bricks.

> **Sovereignty Rule:** All data processed by a Brick remains strictly local to the user's OS. The intelligence and formatting are crowdsourced from the marketplace; the execution and privacy remain entirely sovereign.
